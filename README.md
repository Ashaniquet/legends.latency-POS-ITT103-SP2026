 Purpose of the Program

This program is a Point of Sale (POS) system designed to allow a cashier to:
	•	View available products
	•	Add items to a shopping cart
	•	Remove items from the cart
	•	Display total cost of items	
	• check out items  
  • Generate a receipt 

⸻

 #How to Run the Program
	1.	Ensure Python is installed on your computer
	2.	Download or clone the project from GitHub
	3.	Open the file in a Python environment (e.g., IDLE, VS Code)
	4.	Run the program
	5.	Follow the on-screen menu options


 Required Modifications
	•	Product catalog can be updated inside the program
	•	Prices and quantities can be changed in the dictionary
	•	Modify tax rate if needed
	•	Adjust discount percentage if applicable
	•	Add or remove products based on store needs

Assumptions and Limitations
	•	The program runs in the console (no graphical interface)
	•	User input must be valid (correct product names and quantities)
	•	No database is used (data is not saved after program ends)
	•	Stock updates only occur during program executi
